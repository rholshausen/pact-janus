# Language SDKs

Thin SDK prototypes (plan Phase 6): `typescript/` and `jvm/`. An SDK is generated protocol bindings +
an idiomatic DSL and test-framework integration + the conformance suite run. No matching logic, no
orchestration beyond the engine-protocol operations. Empty until Phase 6 (binding generation starts at
task 6.1); the SDK specification template (task 2.9) governs what goes here.
